# Laboratoryum Web

Frontend React + Vite para Laboratoryum.

## Ejecutar
```bash
cd web
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Estructura
- `src/data/laboratoryum-content.json`: contenido de experimentos.
- `src/components`: grid periódica, filtros y tarjetas.
- `src/pages`: home y detalle de experimento.
- `src/styles`: tokens y estilos globales.
